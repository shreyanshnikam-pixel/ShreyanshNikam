HackPHS · October 2026

      
Sky Sentry

      

        

          
An early-warning system for birds and drones near runways. A phone camera watches the sky, the server finds what is flying, and the control tower hears the warning out loud.

          
Built with Atharv Sharma, Vivan Chowdhury, and Pranav Atreya at HackPHS 2026

How it works

      
From a phone on a tripod to a voice in the tower.

      
    
        
  1. 01 · Camera
    Eyes on the sky
    A phone on a tripod watches the sky. An iPhone app, or any phone browser, streams JPEG frames to the server.
    →
    2. 
        
  2. 02 · Detection
    Find what flies
    The server runs the detection engine on every camera: motion, tracking, wingbeat and flock detection. Detections land in Tiger Data and roll into hourly totals for the charts.
    →
    3. 
        
  3. 03 · Risk
    Green. Yellow. Red.
    Each situation is rated by how many objects there are and how fast they close on the runway.
    →
    4. 
        
  4. 04 · Spoken alert
    The tower hears it
    Red alerts are spoken out loud in the tower, and the dashboard and Arduino beacon light up.
    →
    5. 
        
  5. 05 · Gemini report
    Written up
    Gemini reads the camera snapshot and writes a short incident report. Incidents are saved to MongoDB.
    →
    6. 
        
  6. 06 · Solana record
    Stamped
    Drone reports are hashed and stamped on Solana, so anyone can check a report was never changed.
    →
    7. 
        
  7. 07 · Ask SkySentry
    Ask it
    Answers typed questions using only the last seven days of hourly data, and says “I don’t have data on that” when it doesn’t know.
    8. 
      

    

  


  

    

      
My part: the AI and voice pipeline

      
The path from a red alert to a voice, a report and a record.

      
    
        
  • 0.5 sfrom red alert to audio
    Spoken alerts
    ElevenLabs turns a red alert into audio. If it fails, the browser’s own voice takes over, and alerts are rate-limited so a tower never gets flooded.
    • 
        
  • 3layers of fallback
    Incident reports
    Gemini reads the camera snapshot and writes a short report. If it fails, a backup model takes over, then a template, so a report always gets written.
    • 
        
  • SHA-256hash on Solana devnet
    Solana stamps
    For drone incidents I hash the report with SHA-256 and write the hash to the Solana devnet as a memo, so anyone can check it was never changed. This won Best Use of Solana.
    • 
        
  • 7 daysof data, nothing invented
    Ask SkySentry
    Answers typed questions using only the last seven days of hourly data, and says “I don’t have data on that” when it doesn’t know.
    • 
        
  • 1,300lines across 16 files
    Built to keep running
    The whole system still works without API keys, using template reports and honest status messages. Tests and a mock camera-and-tower setup come with it.
