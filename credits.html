Every asset, creator and licence

Credits.

This site is built from my own code plus free, openly licensed work by other people. Every model, texture, sound, voice, font and library is listed below with who made it, where it came from and the licence that lets me use it.

Built by

Designed and built by Shreyansh Nikam, Livingston High School, New Jersey, 2026. Sky Sentry (HackPHS 2026) was built with Atharv Sharma, Pranav Atreya, and Vivan Chowdhury. Echo (Hack Haven Princeton 2026) was built with Atharv Sharma and Elias Chen.

About the Sky Sentry film

The Sky Sentry film is a dramatization. The airline, its livery, the flight, the radio calls and the readings are fictional. No real airline, airport crew or incident is shown.
